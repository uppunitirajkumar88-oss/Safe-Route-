SAFE ROUTE FEEDBACK LOG — STANDALONE WEB APP

FILES
- index.html: the complete application. It needs no installation, server, or internet connection.
- sample_import_template.csv: an example CSV file showing the columns accepted by Import CSV.

OPEN THE APP ON WINDOWS
1. Extract the ZIP file (right-click it and choose Extract All).
2. Open the extracted safe_route_feedback_log_web folder.
3. Double-click index.html. If prompted, choose Chrome or Microsoft Edge.

DATA AND BACKUPS
The app saves records in browser local storage on the device/browser where it is opened. The data is not automatically synchronized to other computers or browsers. Use the Backup JSON button in the app regularly to save a backup file.

CSV IMPORT
The sample_import_template.csv file has the required fields: route, location, category, severity, and description. Optional columns include status, reporter, deadline, id, created_at, and updated_at. Use the Import CSV button inside the app to import a CSV file.

The app is standalone and does not connect to a network service.
